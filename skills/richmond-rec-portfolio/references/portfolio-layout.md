# Portfolio HTML structure (from Richmond Activity Finder sample)

Standalone static HTML using Tailwind CSS CDN. Match visual structure and hierarchy; do **not** depend on Nuxt/`_nuxt` assets.

## Data semantics

- `membershipScans` (attendance.json) — facility entry / drop-in records (pool, gym, etc.)
- `programHistory` (attendance.json) — registered and attended programs; **categorized by LLM** into `portfolio-data.json` → `attendance` arrays
- Drop-in display is always computed from `membershipScans` in the generator script

## Pipeline

1. Validate `attendance.json`
2. LLM calls `set_portfolio_data` → save `portfolio-data.json` ([portfolio-extraction-prompt.md](portfolio-extraction-prompt.md))
3. `generate_portfolio.py --input attendance.json --portfolio-data portfolio-data.json`

## Sections (top → bottom)

1. **Page chrome** — Print button (`print:hidden` on screen)

2. **Profile card** ← `clientInformation` (portfolio-data) or `personInformation` (attendance.json fallback)

3. **Recent Achievements** ← `activityOutcomes` (portfolio-data preferred)

4. **Drop in count** ← `membershipScans` from attendance.json
   - Flex row: total visits (left box) + per-facility visit rows (right stack)
   - Ignore `attendance.dropInCount` in portfolio-data (optional cross-check only)

5. **Attended Program** ← `attendance` object in portfolio-data.json
   - Non-empty category arrays only; headings from [attendance-category-labels.json](attendance-category-labels.json)
   - Timeline-style left border + category heading + subject card grid

6. **Footer**: Generated by Richmond Rec Portfolio

## Data mapping

| UI | Source |
|----|--------|
| Name, initials, birthdate, age | `portfolio-data.clientInformation` → fallback `attendance.json.personInformation` |
| Achievements | `portfolio-data.activityOutcomes` → fallback `attendance.json.activityOutcomes` |
| Drop in count | `attendance.json.membershipScans` (computed in script) |
| Attended Program cards | `portfolio-data.attendance.{categoryKey}` arrays |

## Output

Write a single self-contained `portfolio.html` (Tailwind via CDN). No Nuxt runtime.
